# BachatBuddy v2

Money on autopilot: write your money rules in your own words, test them on your own history, then let an agent run them with your approval.

> Status: Phase 0 (foundation). Built for the Nebius x NVIDIA Global AI Hackathon.

A rebuilt-from-scratch successor of an earlier prototype. This repository contains only code written in this repository's history.

## Run locally
1. `cp .env.example .env` and fill in the values.
2. `npm install`
3. `npm run dev`
