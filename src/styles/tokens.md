# Khata Design Tokens

## Colors
- paper: #F4EDDC
- ink: #1B1A17
- vermilion: #C8341F (the ONLY accent)
- muted: #5E574A (text on paper)
- dim: #B9B09C (text on ink)

## Fonts
- Serif (khata): Noto Serif (500, 700) with Noto Serif Devanagari (600) as fallback
- Numerals/Labels (num): IBM Plex Mono (400, 500)

## Usage
- `bg-khata-paper`, `text-khata-ink`, `text-khata-vermilion`, `text-khata-muted`, `text-khata-dim`
- `font-khata` for body text, `font-num` for numerals and labels
